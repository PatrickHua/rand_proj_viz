How to Play

  • Objective: Navigate the blue agent to the green goal while avoiding red obstacles
  • Controls: Use the directional buttons or arrow keys to move the agent
  • View Modes:
    • Agent View: True POMDP experience - only see the 3×3 observation, no position info
    • Partial God: See the 5×5 grid but only reveal observed areas
    • God Mode: Full omniscient view of the entire environment
  • Observation: The agent can only see a 3×3 area around itself (shown on the right)
  • Rewards: +1 for reaching the goal for the first time, 0 otherwise
  • Auto Play: Watch the AI policy play automatically
  • Max Steps: Episode ends when maximum steps are reached
  • Keyboard Shortcuts: Arrow keys (move), Space (stay), R (reset), A (auto-play), G (cycle view mode)
